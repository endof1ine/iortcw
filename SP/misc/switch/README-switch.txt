Return to Castle Wolfenstein for the Nintendo Switch (iortcw, single player)
==========================================================================

A homebrew build for Atmosphère, started from the Homebrew Menu. Launch it
from a game held with R (title takeover) for the whole of the console's
memory.

Install
-------
1. Copy this zip's switch folder to the root of the SD card: the program is
   then /switch/iortcw/iortcw.nro.
2. Copy the game's data from your own copy of the game (GOG or Steam), its
   Main folder, to /switch/iortcw/main/ on the SD card:
     pak0.pk3, sp_pak1.pk3 ... sp_pak4.pk3 and scripts/translation.cfg
   (the mp_*.pk3 multiplayer files are not needed). The data is not
   included: it is id Software's.

Controls
--------
Sticks move and look (Halo's response), ZR fires, ZL the weapon's alternate,
R and L the next and previous weapon, A jumps, B crouches, X reloads,
Y uses, L3 toggles sprint, R3 kicks, the d-pad leans (left, right), zooms
(up) and uses an item (down), - opens the notebook and + the menu. The
touchscreen works in the menus. Controls > Controller has the look speed,
invert, deadzone, aim assist and vibration settings.

Saves go to /switch/iortcw/main/save/, the settings to
/switch/iortcw/main/wolfconfig.cfg.
